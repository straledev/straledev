## Projects

**[EuroLeague Defense vs Position](https://github.com/straledev/euroleague-defense-vs-position)** · Python, pandas, Streamlit, GitHub Actions
How many points every EuroLeague team allows to guards, forwards and centers over its last
3, 5 and 10 games, and which position it is weakest against, with an opponent-adjusted season
view. Updated every day. [Live dashboard](https://euroleague-defense-vs-position.streamlit.app)

**[EuroLeague Fantasy Data](https://github.com/straledev/euroleague-fantasy-data)** · Python, pandas, GitHub Actions
Open, daily-updated EuroLeague dataset: game-by-game box scores, fantasy prices,
price history and positions. Every game is verified against the official final score
before it is published, and the pipeline reports anything missing instead of
publishing incomplete data.
