## Projects

**[EuroLeague Fantasy Data](https://github.com/straledev/euroleague-fantasy-data)** · Python, pandas, GitHub Actions
Open, daily-updated EuroLeague dataset: game-by-game box scores, fantasy prices,
price history and positions. Every game is verified against the official final score
before it is published, and the pipeline reports anything missing instead of
publishing incomplete data.

**EuroLeague Defense vs Position** · *in progress*
How many points every EuroLeague team allows to guards, forwards and centers,
adjusted for opponent strength, built on the dataset above.
